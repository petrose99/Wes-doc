`models/bill-pay.ts`, which imports `lib/db.ts` (Prisma/pg) — pulled server-only code into the

moving `ClaimEligibilityReason`/`ClaimEligibility`/`CLAIM_ELIGIBILITY_COPY` into the already
client-safe `lib/payments/eligibility.ts` (beside `ELIGIBILITY_COPY`/`BatchEligibility`, no
`lib/db` in its graph); `models/bill-pay.ts` now re-exports them for its own server callers.

client-manifest gotcha as #225 — a JSX-returning server action needs a server component on the
route's graph to import its client component, or the manifest lookup 500s). **Not yet verified
against a running dev server** — the fix was applied, tsc is clean, but the route itself has not
been re-curled since the edit (context line hit right after). Verify this first, next session.
