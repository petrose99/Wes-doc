## Decisions recorded
Nango runs on Cloud (Pay-as-you-go), not self-hosted. Free self-host lacks webhooks (needed for token-failure detection); Cloud carries webhooks + SOC 2 from its Free tier up at ~$50–500/mo for the map's scale of 50–500 companies. No confirmed South Africa/EU data residency on Cloud today — Enterprise BYOC is the documented fallback if a residency requirement surfaces later. Current Nango version: app v0.71.7, `@nangohq/node` 0.70.8, `@nangohq/frontend` ~0.71.x.
