What a turn costs

You asked "which one am I paying for?" The answer is all of it, every turn. This lesson makes that concrete with your own session from tonight, then checks that it stuck.

The one idea

The model has no memory between calls. Each tool call in a session sends the entire conversation again: system prompt, tool schemas, every earlier tool result, every earlier reply. So the tokens you are billed for a session are not "the load" and not "what changed"; they are the sum of the context at every turn.

tokens sent = Σturns contextturn

Source: Context windows. The cache changes the price of those tokens, not the count (Prompt caching).

That session made 36 tool calls and its context grew from 29K to about 50K. 36 turns × ~39K average ≈ 1.4M, which is the first row. Nothing is hidden; the formula reproduces the log.

A first-turn "load" of 29K is paid 36 times in that session. That is why cutting it from 55K mattered more than any single read.
