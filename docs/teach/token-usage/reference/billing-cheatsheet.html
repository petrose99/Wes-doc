Reading a session's bill

One page to keep beside the run log.

The formula

tokens sent = Σturns contextturn

Cost ≈ cache-read tokens × read rate + cache-write tokens × write rate + uncached × input rate + output × output rate. Rates: pricing page, read fresh.

Read one session from its log

python3 - docs/wayfinder-reports/226/logs/<file>.jsonl <<'EOF'
import json,sys
cc=cr=inp=out=n=0
for l in open(sys.argv[1]):
    if '"usage"' not in l: continue
    j=json.loads(l)
    if j.get('type')=='assistant' and not j.get('parent_tool_use_id'):
        u=j['message']['usage']; n+=1
        cc+=u['cache_creation_input_tokens']; cr+=u['cache_read_input_tokens']
        inp+=u['input_tokens']; out+=u['output_tokens']
print(f"turns {n}  read {cr:,}  write {cc:,}  uncached {inp:,}  output {out:,}")
EOF

The result event at the end carries total_cost_usd when the session finished on its own.

Levers, ranked by what they moved today
