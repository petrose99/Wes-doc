# Integration logo usage rights

As-of date: 2026-09-14

This is a product-marketing research note, not legal advice. It distinguishes a factual text reference (for example, “works with Xero”) from displaying a vendor’s graphical mark. A vendor’s developer registration or OAuth app approval is not treated as a trademark or co-marketing license unless the vendor’s own terms say so.

## Repository inventory

The repository contains shipped connector code for QuickBooks Online and Xero, plus the self-hosted Bigcapital ledger (`lib/integrations/quickbooks`, `lib/integrations/xero`, `lib/integrations/bigcapital`). It contains no Sage, NetSuite, Microsoft Dynamics, SAP, Zoho Books, FreshBooks, Wave, or Pastel connector. The marketing claim should therefore separate “live integration” from “roadmap” even where a vendor permits a factual text reference.

## Operational conclusion for the marketing map

1. For the two shipped external connectors, use plain text such as **“Connects to QuickBooks Online and Xero”** only if the production deployment actually has those connectors enabled. Use vendor marks only after confirming the relevant partner/certification or written brand permission and importing the exact approved assets.
2. Do not build a logo wall for Sage, NetSuite, Dynamics, SAP, Zoho Books, FreshBooks, Wave, or any other vendor that is merely planned. A neutral text list such as **“Additional accounting integrations planned”** avoids implying interoperability, endorsement, or a current partner relationship.
3. Do not call DocuBite an “official partner,” “certified,” “recommended,” or “endorsed” vendor unless the corresponding program has actually granted that status. Plain-text compatibility language and graphical-logo permission are separate checks.
4. Before publication, keep a small approval record for each displayed mark: vendor program/permission, approved asset URL or file, permitted placement/size/colour, required attribution, and expiry/revocation condition. Re-check the vendor’s current terms at publication because these policies change.
