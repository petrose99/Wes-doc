# Workforce policy acknowledgements

Each member of the workforce (employees, contractors, and third parties with production access)
must sign an acknowledgement that they have read the policy set at
[../POLICY-SET.md](../POLICY-SET.md) at hire, at every material policy update, and annually.

Record one row per person per acknowledgement in `acknowledgements.csv` (create it next to this
file — kept out of git only if it contains personal data; if names are already public via
`git log` and GitHub, tracking them here is fine).

Suggested columns:

```
name,email,role,policy_version,acknowledged_at,evidence_link
```

`evidence_link` should point at the signed record (a signed PDF in a document store, a form
submission, or a chat message reacted to with a specific emoji). The record itself is the
evidence for CSF **GV.PO** and **PR.AT**; this file is only the index.
