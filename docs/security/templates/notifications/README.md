# Notification templates

Starter drafts referenced by [../../breach-notification-matrix.md](../../breach-notification-matrix.md).
Each template captures the content elements the corresponding regulation requires. Legal /
privacy counsel MUST review any notification before it is sent — these files exist to shorten
that review, not to replace it.

## Common structure

Every template opens with:

1. Description of what happened (dates, systems, data classes affected).
2. Categories and approximate number of records + data subjects.
3. Likely consequences.
4. Measures taken or proposed to address the breach and mitigate adverse effects.
5. Contact point (DPO or privacy owner) for questions.

## Files

- `gdpr-authority.md` — regulator notification under Art. 33.
- `ukgdpr-ico.md` — ICO notification.
- `hipaa-individual.md` — 45 CFR §164.404 letter to affected individuals.
- `ca-1798.82.md` — California §1798.82 letter.
- `generic-us-state.md` — reusable base for state-level notifications.
- `ftc-health-breach.md` — 16 CFR §318 notification.

Actual template bodies are drafted with counsel when the first triggered incident lands; the
matrix + this index keep the routing decision itself in the repo.
